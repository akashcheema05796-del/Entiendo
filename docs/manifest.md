# Manifest reference — `entiendo.node.yaml`

Field-by-field reference for the node manifest. The authoritative contract is
[`schemas/node.schema.json`](../schemas/node.schema.json); this page is the prose
companion. From SPEC.md §1.2.

Each node is declared by exactly one `entiendo.node.yaml`, colocated with the
module it describes.

## Top-level identity

| Field | Required | Notes |
|---|---|---|
| `apiVersion` | ✓ | Always `entiendo/v1`. Bumped only on deliberate breaking changes. |
| `kind` | ✓ | Always `Node`. |
| `id` | ✓ | Stable, globally unique, dotted (`group.name`). Never renamed silently — a rename is a migration. |
| `name` | ✓ | Human-readable display name. |
| `nodeKind` | ✓ | `compute` \| `state` \| `schema` \| `config` \| `external` \| `pipeline`. Drives how it's drawn. |
| `group` |  | Hierarchy for collapse/expand at scale. |
| `owner` | ✓ | The human accountable. **Never the AI.** |
| `status` |  | `active` \| `deprecated` \| `experimental` (default `active`). |

## `claims` — what the node owns

Required, non-empty. Drives the coverage metric. **Every file is claimed by
exactly one node, or explicitly unclaimed** (Invariant 4). Unclaimed is visible,
not hidden.

## `version` — composite content hash

Generated by the extractor; hand-authored values are placeholders. Dimensions:
`code` (git sha of claimed source), `prompt` (sha256 of claimed prompts),
`config` (sha256 of resolved non-secret config), `model` (model identity — a
version dimension), and `composite` (hash of the above — what you pin, diff, and
revert). See SPEC.md §5.4.

## `contract` — what "correct" means for this node alone

Required. **No node without a contract** (Invariant 3).

| Field | Notes |
|---|---|
| `input` / `output` | JSON-Schema (or `$ref` to one) for valid I/O. |
| `invariants` | Boolean expressions that must hold every execution. |
| `sideEffects` | `none` \| `writes` \| `external` \| `irreversible`. Drives blast radius. Required. |

## `dependencies` — edges

Declared, then **verified against reality** by the extractor — it does not trust
them (Invariant 5). Divergence is a build failure. Keys: `calls`, `reads`,
`writes`, `config`.

## `evals` — tiered, cost-aware

See SPEC.md §5.

- **tier0** — deterministic, <1s, free, every edit. `schema_validation`,
  `invariant_check`, `smoke`. AI may author freely.
- **tier1** — golden datasets, pre-merge. Requires `humanBlessed: true`. Judged
  with `minRuns` + `significance` (never on one run; red only on meaningful
  movement).
- **tier2** — LLM judge, nightly/on-demand. Rubric human-authored, AI-refined.

## `budgets` — health signals

`p95LatencyMs`, `costPerCallUsd`, `tokensPerCall`. For LLM-heavy systems, spend
*is* health.

## `observability`

`spanName` — the OTel span name carrying `entiendo.node_id`, emitted by
`@ent.node()`. Binds runtime traces back to this node.

## `approval`

`required: true` means edits to this node need human sign-off before merge
(SPEC.md §6 step 6) — the original motivation for the tool.
