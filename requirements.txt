# Entiendo runs entirely on Node.js — there is no Python backend.
# See package.json for all runtime dependencies.
#
# Runtime dependencies (managed via npm):
#   @langchain/langgraph       – orchestration graph
#   @langchain/google-genai    – Gemini LLM + embeddings
#   @qdrant/js-client-rest     – vector store client (optional, falls back to in-memory)
#   socket.io                  – real-time token streaming
#   express                    – HTTP server
#   better-sqlite3             – session store (pointer-based state)
#   mermaid                    – client-side diagram rendering
#   react, tailwindcss, motion – UI layer
#
# Optional infrastructure:
#   Qdrant vector DB  – docker run -p 6333:6333 qdrant/qdrant
#                       If not running, the in-memory cosine-similarity fallback
#                       is used automatically — no configuration required.
#
# If a Python analysis sidecar is added in the future, candidates include:
#   gritql      – structural code search/rewrite
#   tree-sitter – AST parsing
#   networkx    – dependency graph analysis
